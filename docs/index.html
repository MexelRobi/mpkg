mpkg
A simple package manager for macOS. Install, update and manage software directly from Git repositories.
Install mpkg
$  curl -fsSL https://mexelrobi.github.io/mpkg/install.sh | bash

Simple package management

mpkg provides a lightweight way to install and manage packages on macOS. Packages are distributed through Git repositories and installed directly on your system.

Install

Install or update mpkg with a single command: 

curl -fsSL https://mexelrobi.github.io/mpkg/install.sh | bash

Features

Simple

One command to install mpkg. No complicated setup.

Updates

The installer automatically uses the newest available mpkg version.

Safe

Package installations are checked for protected paths and file conflicts.

Usage

# Install a package

sudo mpkg -i user/repository

# Update an installed package

sudo mpkg -i user/repository

# Remove a package

sudo mpkg -u user/repository

# List installed packages

sudo mpkg -l

# Uninstall mpkg and delete installed packages that do not have the noclean flag

sudo mpkg -clean
